Six modules, one workspace.

Each module covers one stage: find information, check it, compare models, act on it, keep watching, then share what you've built.

See what changed, and how sure it is.

Signal Radar watches the sources you choose. It records a baseline, reports changes, merges duplicate stories and scores each signal with a visible breakdown. Signals are labelled confirmed, reported or speculative. Alerts follow your quiet hours and daily limits, and the freshness indicator shows when a source was really last checked.

Principles

Built to be trusted, not just used.

These rules are enforced in the code, not just stated in the docs.

01

No invented sources

Citations only point to content that was actually retrieved. Gaps are stated openly.

02

Confidence is not truth

Scores are labelled as estimates, with the evidence and its limits shown next to them.

03

You approve consequences

Sending, posting and writing wait for you, and each approval covers one exact payload.

04

Honest monitoring

NOVA claims continuous monitoring only while a worker is actually running, and freshness is always shown.

05

Untrusted content stays untrusted

Fetched pages are tracked as untrusted, so they can't trigger tools on their own. That limits prompt injection.

06

Your data is portable

Connections need consent and can be revoked. Workspaces export and import as one bundle.

FAQ

Questions.

Does NOVA act on its own?

No. Read-only steps such as searching run automatically. Steps with consequences, such as sending, posting or writing, pause until you approve the exact payload. If the payload changes, it needs a new approval.

How do I know an answer is reliable?

Open the citations, or use Claim DNA to see which passages support or contradict each claim. NOVA's confidence scores are estimates and are labelled that way.

Is Signal Radar always watching?

Only while the background worker is running. NOVA shows when each source was last checked and does not claim live monitoring when the worker is offline.

Can I take my data out?

Yes. Workspaces export as a single bundle that can be imported again. Connections can be revoked, and their synced data deleted.

Which integrations are supported?

This build includes GitHub (OAuth with consent) and RSS feeds. Others will be added only where the provider has a usable API. NOVA does not assume a service is connected.

Get started

Run NOVA locally.

Install the web app and the Python engine, then open the app. You'll need your own model-provider keys in .env. The README covers the details.

terminal
# web app
npm install
# python engine
npm run engine:setup
npm run engine
# in a second terminal
npm run dev
